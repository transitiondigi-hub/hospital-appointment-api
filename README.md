# Hospital Appointment API

## Project Overview
This project supports patient appointment booking through an API.

## Business Objective
Allow patients to book appointments and reduce scheduling conflicts.

## Main Functionalities
- View available appointment slots
- Book an appointment
- View appointment details
- Cancel an appointment
